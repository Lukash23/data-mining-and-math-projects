# Discrete Math

Python implementations of discrete mathematics topics, written for a university course.

| Notebook | What it covers |
|---|---|
| `probability_events.ipynb` | Sample spaces for coin flips, event detection with condition functions, event and complement probabilities, and the binomial distribution for 10 trials |
| `counting_combinatorics.ipynb` | Permutations and combinations using factorials, and coefficients in binomial expansions (uses `input()` prompts) |
| `number_base_conversion.ipynb` | Converting between bases (to decimal and hexadecimal) and binary subtraction with two's complement, checked against Python's result |
| `truth_tables.ipynb` | A truth table generator for Boolean expressions with 2 or 4 variables |
| `linear_function_proof.ipynb` | Graph of y = mx + b and a written proof that (0, b) is the y-intercept |

**Tools:** Python, `math`, NumPy, Matplotlib
